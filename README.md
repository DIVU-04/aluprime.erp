# AluPrime ERP

A clean-room, interactive fenestration ERP prototype inspired by the publicly documented EvA ERP workflow.

## Included

- CRM lead pipeline and quotation tracking
- Project, inventory, production batch, and dispatch workspaces
- Operational dashboard and analytics reports
- Record creation, filtering, global search, and persistent demo data
- Responsive navigation, notifications, settings, and dark mode
- Demo authentication stored locally in the browser

## Run locally

```bash
npm install
npm run dev
```

Use the pre-filled demo credentials on the login screen.

## Production build

```bash
npm run build
npm run preview
```

This repository is an independent implementation. It does not contain or claim access to EvA ERP's proprietary source code, private APIs, or customer data.
