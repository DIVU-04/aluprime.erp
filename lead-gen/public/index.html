Getting the most out of this tool

  • Use the keyword search for anything a Google user would type (“law firms in Surat”, “hotels in Mumbai”, “schools in Jaipur”).
  • Use the radius sweep when you have a specific pin and want every business of a certain type within X km.
  • Google returns at most ~60 places per text search — for a whole city, split it (e.g. by area: “CAs in Bopal”, “CAs in Satellite”, “CAs in Gota”).
  • Emails are not in Google Maps. The tool tries to pull them from each business's own website (usually finds ~40–60%).
  • Every search uses your Google Cloud quota. Places API (New) has a generous free tier — check billing in Google Cloud.
